## What is SVGConverter?

SVGConverter turns SVG files into EPS or raster images for print, web and client delivery, entirely on your own computer.

- **Free trial** — 10 successful files before a licence is required
- **Monthly licence** — one active device at a time
- Batch conversion without uploading your files anywhere

## Auto-update

Once installed, SVGConverter checks this repository for new releases on startup. If a newer version is published here, the app downloads it in the background and prompts you to restart when it is ready.
